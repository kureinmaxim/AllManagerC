# AllManagerC

[![Версия исходников](https://img.shields.io/badge/version-6.0.4-blue?style=flat-square)](VERSION_MANAGEMENT.md)

Порядок обновления версий и команды проверки: [VERSION_MANAGEMENT.md](VERSION_MANAGEMENT.md).

Переключатель русского, английского и упрощённого китайского находится в верхней панели. Выбор сохраняется локально. Английский и китайский переводы пока частичные; непереведённые строки отображаются на русском.

Язык: [English](README.md) · **Русский**

Настольный менеджер сервисов, подписок и учётных данных. Интерфейс работает
в окне PyWebView, а локальный Flask-сервер обслуживает его на `127.0.0.1`
с автоматически выбранным свободным портом.

Репозиторий: [kureinmaxim/AllManagerC](https://github.com/kureinmaxim/AllManagerC).
Основная ветка — `main`. Локальная рабочая папка после объединения проектов
называется `AiManage-Clean`; название приложения — AllManagerC.

## Возможности

- Карточки сервисов: ссылки, провайдер, статус, заметки и иконки.
- Основной и дополнительные аккаунты, просмотр и копирование учётных данных.
- Подписки: стоимость, валюта, период оплаты, дата следующего платежа и чеки.
- Шифрование файла данных и чувствительных полей через Fernet.
- Импорт, экспорт, импорт с внешним ключом и смена ключа шифрования.
- Вход через YubiKey OTP, офлайн-вход со статическим паролем и резервный PIN.
- Светлая/тёмная тема и изменение масштаба интерфейса.
- Сборка приложения для macOS и Windows с общей иконкой AllManagerC.

Механизмы входа и шифрования имеют ограничения: перед хранением важных паролей
прочитайте [SECURITY.md](SECURITY.md). Приложение предназначено для локального
использования, не для публикации Flask-сервера в интернете.

## Текущее состояние

В `main` объединены AiManage и его GitHub-версия. Возвращены дополнительные
аккаунты, заметки на карточках, массовое удаление с подтверждением и возврат
к карточке после редактирования. Исправлены сохранение дополнительных паролей,
маршруты настроек и перешифровка вложенных данных.

Текущая версия конфигурации — `6.0.0`; код содержит объединённую версию проекта и
частичную локализацию. Установщики 6.0.0 ещё не опубликованы в GitHub Releases.

Проверены 10 регрессионных тестов и два запуска нативного приложения на
macOS 26.6.2 / Apple Silicon arm64 с Python 3.13.9. Новые установщики Windows
и работа на Linux в рамках объединения не проверялись.

## Быстрый старт из исходников

```bash
git clone https://github.com/kureinmaxim/AllManagerC.git
cd AllManagerC
```

Если у вас уже есть рабочая папка AiManage-Clean, используйте её.
Окружение создаётся отдельно на каждой ОС; переносить `.venv` между платформами
не следует.

### macOS

```bash
python3 -m venv .venv
.venv/bin/python -m pip install Flask requests python-dotenv cryptography Werkzeug Jinja2 pywebview yubico-client
.venv/bin/python run_app.py
```

На этом Mac рабочее окружение `.venv` уже подготовлено. Для запуска достаточно
последней команды. На macOS используется Cocoa/WebKit, дополнение Qt не требуется.

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_app.py
```

Прямой вызов Python не требует активации окружения или изменения ExecutionPolicy.
Linux и подробная диагностика описаны в [DEPLOYMENT.md](DEPLOYMENT.md).

Оба входа — `run_app.py` и `app.py` — запускают GUI. Отдельного готового серверного
режима нет. Адрес с фактическим портом выводится в терминале при запуске.

## Первый запуск и данные

При отсутствии ключа приложение создаёт `SECRET_KEY` и сохраняет его в `.env`.
Если активный файл базы отсутствует, создаётся пустая база. Это не восстановление
данных старой установки.

1. Проверьте состояние защиты и настройте вход через интерфейс YubiKey.
2. Настройте собственный резервный PIN и секрет сессии по [SECURITY.md](SECURITY.md).
3. Добавьте сервис и при необходимости дополнительные аккаунты.
4. Для старой базы используйте импорт с её исходным ключом.
5. Сохраните резервную копию данных, ключа и вложений.

Расположение данных готового приложения:

- macOS: `~/Library/Application Support/AllManagerC`.
- Windows: `%APPDATA%\AllManagerC`.
- Linux: `~/.local/share/AllManagerC`.

В режиме разработки данные находятся в рабочей папке проекта. Значимые файлы:
`.env`, `config.json`, `yubikey_config.json`, каталоги `data`, `uploads`, `logs`.
Полный экспорт содержит базу **вместе с ключом**; храните такой архив как секрет.

Базы двух исходных проектов оставлены отдельно по решению пользователя.
Локальные резервные копии находятся в `.local-backups/before-unification-20260923/`
и не отправляются в Git. Подробнее — [результат объединения](docs/UNIFICATION.md).

## Сборка и установка

Подробные шаги, требования и правила публикации: [BUILD_MACOS.md](BUILD_MACOS.md).

Для macOS, после установки зависимостей сборки:

```bash
.venv/bin/python -m pip install pyinstaller pillow
bash build_macos.sh
```

Скрипт создаёт отдельную папку `dist/macos-arm64-ДАТА-ВРЕМЯ` с `.app`, DMG
и SHA256. Он не удаляет прежние сборки, не пересоздаёт окружения и не устанавливает
зависимости автоматически. В macOS-сборку включаются чистые настройки без личных
баз, `.env` и конфигурации YubiKey.

Локальный результат от 23 сентября 2026:

```text
dist/macos-arm64-v6.0.0-final/AllManagerC_Installer_v6.0.0_arm64.dmg
```

Размер — около 21 МБ; контрольная сумма SHA256:

```text
13141218e565d64eb77483aa3be3bf99f785dda0ba7ab4aa08e2b9b453e121ff
```

Этот DMG создан локально и не опубликован нами в GitHub Releases. После клонирования
репозитория его нужно собрать. Образ проверен через `hdiutil verify`, приложение
имеет локальную ad-hoc подпись; нотариальное заверение Apple не выполнялось.
Для установки откройте DMG и перетащите AllManagerC в Applications.

Windows собирается на Windows через `build_windows.py`, затем `AllManagerC.iss`
в Inno Setup. Перед распространением проверьте включаемый `config.json`: Windows-
скрипт пока использует конфигурацию рабочей папки. Подробности — в SECURITY.md.

## Проверки и разработка

В активном окружении или с явным путём к его Python:

```bash
python -m unittest discover -s tests -v
python check_env.py
```

Тесты используют временные профили и синтетические данные. Они проверяют аккаунты,
сохранение и перешифровку, маршруты, ограничение управления YubiKey, переносимость
путей, подключение иконки и сохранение ключа при повторном запуске.

Основные файлы:

- `app.py`, `run_app.py` — приложение и запуск GUI.
- `runtime_paths.py` — папка данных упакованного приложения.
- `yubikey_auth.py`, `security_logger.py` — вход и журнал событий безопасности.
- `templates`, `static` — интерфейс и ресурсы.
- `tools/build_macos.py`, `build_macos.sh` — сборка macOS.
- `build_windows.py`, `AllManagerC.iss` — сборка Windows.
- `tests` — регрессионные тесты.
