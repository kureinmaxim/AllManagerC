# Единый AllManagerC

Основой выбран AiManage-Clean: здесь находится GitHub remote и более новая
кроссплатформенная версия. Истории Git обоих каталогов сохранены на месте;
объединение сделано на уровне исходного кода, без переписывания истории и публикации.

## Что вошло

Из GitHub-версии сохранены Windows/macOS сборки, запуск сервера с выбором порта,
масштаб интерфейса, настройка разрешённых public ID YubiKey, документация релизов
и исходные иконки `static/images/ALLc.png` и `static/images/icon.ico`.

Из AiManage возвращены несколько аккаунтов у одного сервиса, их шифрование,
отображение и копирование; заметки на карточках; удаление всех сервисов через
подтверждение; возврат к карточке после редактирования и отмена по Escape.
Дополнительная информация для входа из GitHub-версии сохранена вместе с аккаунтами.
Учебные материалы и руководства перенесены в `docs/legacy/`; это исторические
справочные материалы, их старые команды и пути не являются текущими инструкциями.

## Исправления при объединении

- Пустой пароль дополнительного аккаунта при редактировании сохраняет старый.
  Удаление соседней строки не переносит чужой пароль на другой аккаунт.
- Смена ключа перешифровывает также вложенные пароли и дополнительные аккаунты.
  Расшифрованные поля интерфейса не попадают в сохранённые данные.
- Восстановлены отдельные POST-маршруты смены, проверки и генерации ключа.
- Управление уже настроенными ключами YubiKey требует входа.
- `run_app.py` использует общий GUI-вход `app.py`; принудительное завершение
  процессов на порту 5050 и жёсткий выбор macOS GUI удалены.
- Удалён вывод содержимого `.env` и секретов окружения в консоль.
- Сборки не включают содержимое локальной папки `data`.
- При переносе с Windows старый путь базы разрешается через локальную `data`,
  если там существует файл с тем же именем.

## Данные и резервные копии

По решению пользователя рабочие базы не объединены и не восстановлены из истории.
Активная база AiManage содержит 0 записей. Конфигурация AiManage-Clean ссылается
на отсутствующий здесь Windows-путь. При обычном запуске существующая логика
приложения создаст пустую базу, если активный файл отсутствует.

Все локальные `data`, `uploads`, `.env`, `config.json`, `yubikey_config.json` обоих
проектов скопированы отдельно в `.local-backups/before-unification-20260923/`.
Там же сохранён снимок tracked-файлов исходной GitHub-версии (`github-source`).
Не публикуйте эту папку: она содержит ключи и личные данные. Исходный AiManage
не изменён; его имеющиеся локальные удаления документов сохранены.

Когда будет выбрана база, импортируйте её через настройки вместе с её исходным
ключом. Не подменяйте `.env` одного проекта другим поверх уже действующей базы.

## Проверка

`python -m unittest discover -s tests -v`

Девять регрессионных тестов используют временный каталог и синтетические данные:
создание/изменение аккаунтов, страницы, отсутствие открытых паролей при сохранении,
внешний ключ, смена ключа, маршруты настроек, массовое удаление, защита управления
YubiKey, переносимость пути и подключение иконки. Реальные базы тесты не открывают.

Полная сборка установщиков, запуск нативного GUI и проверка физического YubiKey
в этом объединении не выполнялись.
