# 🔧 Руководство по Восстановлению Данных

## Проблема: "Неверный ID сервиса" или потеря данных

### Симптомы
- Ошибка "Неверный ID сервиса" при попытке редактирования/удаления.
- Сервисы отображаются, но нельзя с ними взаимодействовать.
- Поврежденные файлы данных (маленький размер).
- Полное исчезновение сервисов.

### Причина
Повреждение активного файла данных или потеря корректных ID сервисов.

## 🔍 Диагностика

### 1. Проверка активного файла
```bash
# Посмотреть конфигурацию
cat config.json | grep active_data_file

# Проверить размер файла
ls -la data/ai_services*.enc
```

### 2. Анализ файлов данных
```bash
# Запустить диагностику
python3 tools/data_integrity.py
```

## 🛠️ Решение

### Автоматическое восстановление
```bash
# Запустить скрипт восстановления
python3 tools/fix_data_integrity.py
```

### Ручное восстановление с локальных бэкапов

#### 1. Найти рабочую резервную копию
```bash
# Посмотреть все резервные копии
ls -la data/*.backup*

# Проверить содержимое резервной копии
# (замените 'data/your_backup_file' на реальное имя файла)
python3 -c "
import os, json
from cryptography.fernet import Fernet
with open('.env', 'r') as f:
    key_line = next((line for line in f if line.startswith('SECRET_KEY=')), None)
    secret_key = key_line.split('=', 1)[1].strip() if key_line else None
if not secret_key: raise ValueError('SECRET_KEY не найден в .env')
backup_file = 'data/your_backup_file'
try:
    with open(backup_file, 'rb') as f: encrypted_data = f.read()
    fernet = Fernet(secret_key.encode())
    decrypted_data = fernet.decrypt(encrypted_data)
    data = json.loads(decrypted_data.decode('utf-8'))
    print(f'Сервисов: {len(data)}')
    for service in data: print(f'- {service.get(\"name\")} (ID: {service.get(\"id\")})')
except Exception as e: print(f'Ошибка: {e}')
"
```

#### 2. Восстановить данные
```bash
# Скопировать резервную копию
cp "data/your_backup_file" "data/ai_services_restored.enc"

# Обновить конфигурацию
# Отредактируйте config.json, изменив active_data_file на:
# "active_data_file": ".../data/ai_services_restored.enc"
```

#### 3. Проверить восстановление
```bash
# Запустить приложение
python3 run_app.py

# Или проверить через viewer
python3 tools/ai_services_viewer.py
```

### Восстановление из Git (крайний случай)
Если локальные бэкапы повреждены или отсутствуют, но файл данных был случайно добавлен в Git, его можно восстановить из истории коммитов.

#### 1. Найти коммит с рабочей версией файла
```bash
# Показать историю изменений для папки data
git log -- data/
```
Найдите в списке хеш коммита (`commit <hash>`), когда файл данных был еще в рабочем состоянии.

#### 2. Восстановить файл из коммита
```bash
# Замените <hash> и <path_to_file> на ваши значения
git checkout <hash> -- <path_to_file>

# Пример:
git checkout a1b2c3d4 -- data/ai_services_merged_20250718_071344.enc.backup_20250718_123033
```
Эта команда восстановит указанный файл до состояния на момент выбранного коммита.
