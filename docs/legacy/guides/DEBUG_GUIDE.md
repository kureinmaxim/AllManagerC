# 🔍 Руководство по отладке AI Manager

## 🚀 Быстрая отладка

### 1. Запуск и доступ
```bash
# Активировать окружение и запустить приложение
source venv/bin/activate && python3 run_app.py

# Адрес для доступа в браузере: http://127.0.0.1:5050
```

### 2. Ключевые инструменты
-   **Инструменты разработчика (DevTools)**: `Cmd + Option + I` (macOS) или `F12` (Windows/Linux).
-   **Вкладки для отладки**: `Console` (ошибки JS), `Network` (сетевые запросы, ошибки 500), `Elements` (вёрстка).

### 3. Основные команды диагностики
```bash
# Проверка доступности страниц (в терминале)
curl -I http://127.0.0.1:5050/
curl -I http://127.0.0.1:5050/yubikey/login

# Проверка состояния в консоли браузера
console.log('Количество сервисов:', document.querySelectorAll('.card-carousel-card').length);
```

## ⚙️ Детальная отладка через браузер

### Google Chrome (рекомендуется)

#### Основные вкладки для отладки
-   **Elements (Элементы)**: Просмотр HTML структуры и редактирование CSS в реальном времени.
-   **Console (Консоль)**: Просмотр ошибок JavaScript, выполнение команд.
-   **Network (Сеть)**: Мониторинг HTTP запросов, проверка статусов (200, 302, 500).
-   **Sources (Источники)**: Отладка JavaScript кода, установка точек останова.
-   **Application (Приложение)**: Просмотр cookies, localStorage и данных сессии.

### Отладка Internal Server Error (500)
1.  **Проверьте консоль терминала**, в которой запущен `app.py`, на наличие сообщений об ошибках Python.
2.  **Откройте вкладку Network** в DevTools, обновите страницу и найдите запрос со статусом 500.
3.  **Изучите вкладку Response** для этого запроса, чтобы увидеть HTML-страницу с трейсбеком ошибки Flask.

### Отладка проблем с YubiKey
1.  Проверьте доступность страниц: `/yubikey/login`, `/yubikey/setup`.
2.  Используйте вкладку **Network** для отслеживания POST-запроса при отправке OTP.
3.  Проверьте **Application -> Cookies** на наличие `session` и `yubikey_authenticated`.

### Отладка проблем с отображением
1.  **Используйте инспектор элементов (Elements)**, чтобы проверить, какие CSS-стили применяются к проблемному элементу.
2.  **Проверьте консоль (Console)** на ошибки JavaScript, которые могли помешать выполнению скриптов.
3.  **Во вкладке Network** убедитесь, что все CSS и JS файлы загрузились со статусом 200.

## 🛠️ Продвинутые методы

### Анализ производительности
1.  **Откройте вкладку Performance** в DevTools.
2.  Нажмите "Запись", выполните действие (например, загрузку страницы).
3.  Остановите запись и проанализируйте диаграмму выполнения: время загрузки, выполнение JS, рендеринг.

## 🚨 Частые проблемы и решения

-   **"Address already in use"**: Порт 5050 занят.
    -   **Решение**: `lsof -ti:5050 | xargs kill -9`
-   **Проблемы с сессией/входом**: Не сохраняется состояние.
    -   **Решение**: Очистите cookies и cache в DevTools (вкладка Application) и перезапустите браузер.
-   **Модуль не найден**: `ImportError` при запуске.
    -   **Решение**: `pip install --force-reinstall -r requirements.txt`
