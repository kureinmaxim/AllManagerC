## Описание Файлов и Директорий

### 📖 Главная документация

- **`README.md`**: **Главная документация проекта** - полное описание AI Manager с быстрым стартом, структурой проекта, безопасностью, ссылками на все руководства в папке `guides/` и стратегии разработки в папке `strategies/`. Содержит статистику проекта, инструкции по сборке и поддержке.

### Основные файлы

- **`app.py`**: Сердце приложения. Содержит:
  - Веб-сервер на базе **Flask**, который обрабатывает все запросы (показать, добавить, удалить AI-сервис).
  - Логику шифрования/дешифрования данных с помощью ключа из файла `.env`.
  - Интеграцию с **PyWebView** для отображения веб-интерфейса в нативном окне macOS.
  - Функцию корректного завершения работы (`/shutdown`) для освобождения порта.
  - **⭐ НОВОЕ**: Расширенные функции импорта/экспорта:
    - `/data/export` - экспорт данных (.enc файл)
    - `/data/export_key` - экспорт ключа шифрования (.env файл) 
    - `/data/export_package` - полный экспорт (ZIP с данными, ключом и файлами)
    - `/data/import_external` - импорт с объединением из другой установки
  - **⭐ НОВОЕ**: Система аутентификации YubiKey:
    - `/yubikey/login` - страница входа с OTP
    - `/yubikey/setup` - настройка ключей YubiKey
    - `/yubikey/instructions` - инструкции по получению ключей
    - `/yubikey/logout` - выход из системы
    - Поддержка множественных ключей YubiKey

- **`run_app.py`**: Скрипт запуска GUI приложения. Этот файл отвечает за:
  - **Запуск Flask сервера** в отдельном потоке на порту 5050
  - **Создание нативного окна** с помощью PyWebView
  - **Управление жизненным циклом** приложения (запуск, остановка)
  - **Обработку закрытия окна** с корректным завершением Flask сервера
  - **Настройку GUI параметров** (размер окна, заголовок, поведение)
  
  **Зачем два файла?** Это разделение ответственности:
  - `app.py` содержит всю бизнес-логику и веб-сервер
  - `run_app.py` отвечает только за запуск GUI и управление окном
  - Такое разделение позволяет запускать приложение разными способами:
    - `python3 app.py` - только веб-сервер (для разработки)
    - `python3 run_app.py` - полное GUI приложение
    - Собранное `.app` использует `run_app.py` как точку входа

- **`test_app_comprehensive.py`**: Комплексные автоматизированные тесты для проверки функциональности приложения.
- **`test_quick.py`**: Быстрые тесты для разработки, которые можно запускать напрямую.
- **`run_tests.py`**: Скрипт для запуска различных типов тестов (например, запуск всех тестов, запуск отдельных тестов).
- **`TESTING_GUIDE.md`**: Подробное руководство по тестированию, включающее инструкции по запуску тестов, настройке окружения и интерпретации результатов.

- **`build_macos.py`**: Сборочный скрипт для macOS. Автоматизирует процесс упаковки Python-кода в готовое к распространению приложение (`.app`) с помощью **PyInstaller**.
  - **⭐ НАДЕЖНАЯ СБОРКА**: Скрипт был улучшен для решения проблем с зависимостями и путями.
  - **Автоматическое создание иконки**: Гарантированно создает файл `.icns` из `static/images/icon.png` перед сборкой.
  - **Стабильный вызов PyInstaller**: Использует `python3 -m PyInstaller` для запуска, что исключает ошибки, связанные с переменной `PATH`.
  - Обновляет дату в `config.json` перед сборкой.

- **`requirements.txt`**: Стандартный файл, перечисляющий все библиотеки Python, необходимые для работы проекта (`Flask`, `pywebview`, `cryptography` и т.д.).

- **`config.json`**: ⭐ **ОБНОВЛЕННЫЙ** файл настроек. Содержит:
  - **`SECRET_KEY_FILE`**: Путь к файлу с секретным ключом (по умолчанию `.env`)
  - **`app_info`**: Информация о приложении:
    - `version`: Версия приложения (5.5.2)
    - `release_date`: Дата релиза (30.07.2025)
    - `developer`: Имя разработчика
    - `description`: Описание приложения
    - `last_updated`: Дата последнего обновления
  - **`service_urls`**: URL-адреса внешних сервисов:
    - `ip_check_api`: API для проверки IP-адреса
    - `general_ip_test`: Сервис для тестирования IP
    - `general_dns_test`: Сервис для тестирования DNS
  - **`active_data_file`**: Путь к активному файлу данных (data/ai_services.enc)

- **`env.example`**: ⭐ **НОВЫЙ** файл-пример переменных окружения. Содержит:
  - **`SECRET_KEY`**: Секретный ключ для шифрования данных (требует замены на реальный)
  - **`YUBIKEY_STATIC_PASSWORD`**: Статический пароль для YubiKey (опционально)
  - Служит шаблоном для создания файла `.env` при первом запуске

- **`.env`**: Содержит секретный ключ шифрования `SECRET_KEY` и, опционально, `YUBIKEY_STATIC_PASSWORD` для офлайн-входа. **ВАЖНО**: Этот файл не попадает в Git для безопасности.

- **⭐ `generate_key.py`**: Утилита для генерации нового `SECRET_KEY` в файле `.env`. Автоматически создает криптографически стойкий ключ для шифрования данных.

- **`decrypt_tool.py`**: Инструмент командной строки для просмотра зашифрованных данных без запуска основного приложения.

- **`ai_services_schema.json`**: Документированная схема данных для AI-сервисов с описанием всех полей и их типов.

- **`ai_services_viewer.py`**: Утилита для просмотра и анализа структуры данных AI-сервисов.

- **⭐ `DEBUG_GUIDE.md`**: Подробное руководство по отладке приложения через браузер. Содержит:
  - Полное описание инструментов Chrome DevTools
  - Методы диагностики различных проблем
  - Продвинутые техники отладки
  - Решение типичных проблем веб-приложений

- **⭐ `QUICK_DEBUG.md`**: Краткое руководство по отладке для быстрого старта. Включает:
  - Основные команды отладки
  - Частые проблемы и быстрые решения
  - Ссылки на подробные руководства

- **⭐ `yubikey_auth.py`**: Модуль аутентификации YubiKey. Содержит:
  - Класс `YubiKeyAuth` для управления множественными ключами
  - Методы добавления, удаления и проверки ключей
  - Интеграцию с Yubico API для верификации OTP
  - Декоратор `@require_auth` для защиты маршрутов
  - **⭐ НОВОЕ**: Гибридную аутентификацию: онлайн через OTP и офлайн через статический пароль, если нет интернета.
  - Поддержку обратной совместимости со старым форматом ключей

## Архитектура Файлов

### Разделение ответственности между app.py и run_app.py

**`app.py`** - Основной модуль приложения:
- ✅ **Бизнес-логика**: Все функции работы с AI-сервисами
- ✅ **Веб-сервер Flask**: Маршруты, обработчики запросов
- ✅ **Шифрование/дешифрование**: Работа с данными
- ✅ **YubiKey аутентификация**: Логика безопасности
- ✅ **Импорт/экспорт**: Функции переноса данных
- ❌ **НЕ содержит**: GUI логику, управление окнами

**`run_app.py`** - Скрипт запуска GUI:
- ✅ **Управление GUI**: Создание окна PyWebView
- ✅ **Многопоточность**: Запуск Flask в отдельном потоке
- ✅ **Жизненный цикл**: Запуск/остановка приложения
- ✅ **Обработка событий**: Закрытие окна, завершение работы
- ❌ **НЕ содержит**: Бизнес-логику, веб-сервер

### Преимущества такой архитектуры:

1. **Гибкость запуска**:
   ```bash
   # Только веб-сервер (для разработки)
   python3 app.py
   
   # Полное GUI приложение
   python3 run_app.py
   
   # Собранное приложение
   ./AllManager.app
   ```

2. **Разделение ответственности**:
   - Разработчики могут работать с `app.py` независимо от GUI
   - GUI можно изменить без влияния на бизнес-логику
   - Тестирование веб-сервера отдельно от GUI

3. **Переиспользование кода**:
   - `app.py` может использоваться как веб-API
   - `run_app.py` может работать с разными веб-приложениями
   - Собранное приложение использует тот же код

4. **Упрощение отладки**:
   - Проблемы с GUI → смотрим `run_app.py`
   - Проблемы с логикой → смотрим `app.py`
   - Четкое разделение проблем

## Алгоритм Работы Программы

1. **Запуск**: Пользователь запускает приложение одним из способов:
   - **GUI режим**: `python3 run_app.py` или `AiManager.app` (собранное приложение)
   - **Веб режим**: `python3 app.py` (только для разработки)

2. **Инициализация**:
   - **В GUI режиме**: `run_app.py` запускает Flask сервер из `app.py` в фоновом потоке
   - **В веб режиме**: `app.py` запускает Flask сервер напрямую
   - Сервер начинает "слушать" локальный адрес (`http://127.0.0.1:5050`)
   - Инициализируется модуль YubiKey аутентификации (`yubikey_auth.py`)
   - **В GUI режиме**: PyWebView создает нативное окно приложения и загружает веб-страницу
   - Применяется сохранённый масштаб интерфейса и тема из cookies

3. **⭐ Аутентификация YubiKey**:
   - Если защита YubiKey включена, пользователь перенаправляется на страницу входа.
   - **Онлайн-режим**: При наличии интернета, пользователь касается YubiKey, и сгенерированный OTP-код проверяется через Yubico API.
   - **Офлайн-режим**: Если интернет отсутствует, пользователь удерживает кнопку YubiKey для ввода статического пароля, который проверяется локально.

4. **Отображение данных**:
   - Браузер в окне запрашивает главную страницу (`/`)
   - Flask получает запрос, загружает зашифрованный файл `data/ai_services.json.enc`, расшифровывает его с помощью ключа из `.env` и передает список AI-сервисов в HTML-шаблон `index.html`
   - Пользователь видит готовый список своих AI-сервисов в виде красивых карточек с информацией о подписках

5. **Взаимодействие**: Любое действие пользователя (нажатие кнопки "Редактировать", "Добавить", изменение масштаба, переключение темы, импорт/экспорт, настройка YubiKey) отправляет запрос на сервер Flask, который обрабатывает его, изменяет данные, снова шифрует их и сохраняет обратно в `ai_services.json.enc`

6. **⭐ Экспорт/Импорт**: 
   - **Экспорт**: Создаются временные файлы или ZIP архивы, которые автоматически удаляются после скачивания
   - **Импорт**: Внешние файлы проверяются, расшифровываются и объединяются с существующими данными

7. **⭐ Управление YubiKey**:
   - Добавление новых ключей через `/yubikey/setup`
   - Удаление ключей с подтверждением
   - Просмотр инструкций по получению ключей

8. **Завершение работы**:
   - **В GUI режиме**: Пользователь нажимает на красный крестик закрытия окна → PyWebView перехватывает событие → отправляется запрос на `/shutdown` → Flask корректно завершает работу
   - **В веб режиме**: Ctrl+C в терминале → Flask завершает работу напрямую

- **⭐ Поддержка множественных ключей**: Возможность импорта данных с разными ключами шифрования для переноса между установками
- URL-адреса панелей управления маскируются в интерфейсе для защиты от случайных взглядов 
- **⭐ Безопасные временные файлы**: Автоматическое удаление временных файлов после экспорта
- **⭐ Валидация данных**: Проверка целостности и корректности импортируемых данных
- **⭐ Двухфакторная аутентификация YubiKey**: Физическая защита приложения с помощью YubiKey
- **⭐ Безопасное управление ключами**: Добавление новых YubiKey только при наличии доступа
- **⭐ OTP верификация**: Проверка одноразовых паролей через официальный Yubico API
- **⭐ Офлайн-аутентификация**: Возможность входа по статическому паролю YubiKey при отсутствии интернет-соединения.
- **⭐ Улучшенная обработка ошибок**: Пользовательский интерфейс для ошибок 500

## Использование YubiKey Аутентификации

### Первоначальная Настройка
1. Получите YubiKey и зарегистрируйтесь на [Yubico Developer Console](https://developers.yubico.com/)
2. Создайте новое приложение и получите Client ID и Secret Key
3. В приложении: **Настроить YubiKey** → **Как получить ключи Yubico?**
4. Следуйте инструкциям для получения API ключей
5. Добавьте первый ключ в приложение

### Управление Ключами
- **Добавление ключей**: Только при наличии доступа к приложению
- **Удаление ключей**: Через настройки YubiKey с подтверждением
- **Резервные ключи**: Рекомендуется иметь несколько ключей
- **Восстановление доступа**: Удаление файла `yubikey_config.json` в крайнем случае

### Процесс Входа
1. Вставьте YubiKey в USB-порт
2. **Если есть интернет (онлайн-вход)**: Коснитесь золотого контакта на ключе. Код будет вставлен автоматически.
3. **Если нет интернета (офлайн-вход)**: Удерживайте золотой контакт на 2-3 секунды. Статический пароль будет вставлен автоматически.
4. Нажмите "Войти".

### Безопасность
- **Физическая защита**: YubiKey невозможно скопировать удаленно
- **OTP коды**: Каждый код уникален и используется только один раз
- **Множественные ключи**: Поддержка основного и резервных ключей
- **Автоматическая защита**: После добавления первого ключа защита включается автоматически
