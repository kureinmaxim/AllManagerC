# 🔐 Секретный вход в AI Manager

## Описание

AI Manager v5.5.0 включает в себя секретную функцию входа, которая позволяет обойти YubiKey аутентификацию в экстренных случаях.

## Как использовать

### Способ активации
1. Найдите в футере приложения текст "Разработчик: Куреин М.Н."
2. **Дважды кликните левой кнопкой мыши** на фамилию "Куреин"
3. Появится модальный диалог для ввода PIN-кода

### PIN-код
- **PIN**: `5421`
- **Формат**: 4 цифры
- **Безопасность**: PIN вводится в скрытом поле

### Процесс входа
1. Двойной клик на "Куреин" → открывается модальный диалог
2. Введите PIN `5421` в поле ввода
3. Нажмите "Войти" или клавишу Enter
4. При успешном вводе:
   - Показывается сообщение "Аутентификация успешна"
   - Модальный диалог закрывается
   - Страница перезагружается
   - Вы получаете доступ к приложению

### Процесс блокировки
1. При вводе неправильного PIN:
   - Показывается сообщение о блокировке
   - Поле ввода и кнопка блокируются
   - Запускается таймер обратного отсчета (30 секунд)
2. Во время блокировки:
   - Все попытки входа отклоняются
   - Показывается оставшееся время
   - Поле ввода остается заблокированным
3. После истечения блокировки:
   - Поле ввода автоматически разблокируется
   - Таймер исчезает
   - Можно повторить попытку входа

### Обработка ошибок
- **Неверный PIN**: Показывается сообщение "Неверный PIN-код"
- **Пустое поле**: Показывается сообщение "Введите PIN-код"
- **Ошибка соединения**: Показывается сообщение "Ошибка соединения с сервером"
- **Блокировка**: При неправильном PIN вход блокируется на 30 секунд с таймером обратного отсчета

## Технические детали

### Файлы реализации
- `templates/layout.html` - JavaScript обработчик двойного клика и модальный диалог
- `app.py` - маршрут `/secret/login` для обработки запросов
- `yubikey_auth.py` - функция `secret_authenticate()` для проверки PIN

### Безопасность
- PIN-код проверяется на сервере
- Сессия помечается флагом `secret_login_used`
- Все попытки входа логируются
- Модальный диалог создается динамически и удаляется после использования
- **Защита от перебора**: При неправильном PIN вход блокируется на 30 секунд
- **Визуальная индикация**: Показывается таймер обратного отсчета во время блокировки
- **Автоматический сброс**: Блокировка сбрасывается автоматически по истечении времени

### API Endpoint
```
POST /secret/login
Content-Type: application/x-www-form-urlencoded

pin=5421
```

**Ответ при успехе:**
```json
{
  "success": true,
  "message": "Аутентификация успешна"
}
```

**Ответ при ошибке:**
```json
{
  "success": false,
  "message": "Неверный PIN-код"
}
```

**Ответ при блокировке:**
```json
{
  "success": false,
  "message": "Секретный вход заблокирован на 30 секунд",
  "blocked": true,
  "remaining_seconds": 30
}
```

## Назначение

Секретный вход предназначен для:
- Экстренного доступа к приложению при недоступности YubiKey
- Тестирования системы без физического ключа
- Резервного метода аутентификации

## Примечания

- Секретный вход работает на всех страницах приложения
- Функция полностью интегрирована с существующей системой YubiKey
- PIN-код захардкожен и не может быть изменен через интерфейс
- Все попытки использования логируются для аудита безопасности
