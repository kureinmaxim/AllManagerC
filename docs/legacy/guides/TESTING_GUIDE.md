# 🧪 Руководство по Тестированию AI Manager

## 📋 Обзор

Это руководство описывает комплексное тестирование приложения AI Manager v4.3.5. Включает автоматизированные тесты, ручное тестирование и диагностику проблем.

## 🚀 Быстрый Старт

### Автоматизированное тестирование

```bash
# Запуск быстрых тестов
python3 tests/run_tests.py --mode quick

# Запуск полных тестов
python3 tests/run_tests.py --mode full

# Результат будет сохранен в JSON файл
# test_results_YYYYMMDD_HHMMSS.json
```

### Ручное тестирование

```bash
# Запуск приложения для ручного тестирования
python3 run_app.py

# Или только веб-сервер
python3 app.py
```

## 🧪 Детальное Тестирование

### 1. Тестирование Веб-сервера

```bash
# Запуск сервера
python3 app.py

# В другом терминале - тестирование
curl -I http://127.0.0.1:5050/
curl http://127.0.0.1:5050/ | grep "AI Manager"
```

**Ожидаемый результат:**
- Код ответа 200
- Наличие "AI Manager" в HTML

### 2. Тестирование GUI

```bash
# Запуск GUI приложения
python3 run_app.py

# Проверка процессов
ps aux | grep python3
lsof -i :5050
```

**Ожидаемый результат:**
- Открытие окна приложения
- Загрузка главной страницы
- Корректное отображение интерфейса

### 3. Тестирование YubiKey

```bash
# Проверка модуля
python3 -c "import yubikey_auth; print('OK')"

# Тестирование страниц
curl http://127.0.0.1:5050/yubikey/login
curl http://127.0.0.1:5050/yubikey/setup
curl http://127.0.0.1:5050/yubikey/instructions
```

**Ожидаемый результат:**
- Успешный импорт модуля
- Код ответа 200 для всех страниц

### 4. Тестирование Экспорта

```bash
# Экспорт данных
curl -o test_export.enc http://127.0.0.1:5050/data/export

# Экспорт ключа
curl -o test_key.env http://127.0.0.1:5050/data/export_key

# Полный экспорт
curl -o test_package.zip http://127.0.0.1:5050/data/export_package

# Проверка файлов
ls -la test_*.enc test_*.env test_*.zip
```

**Ожидаемый результат:**
- Создание файлов с размером > 0
- Корректное содержимое .env файла

### 5. Тестирование Форм

```bash
# Тест добавления сервиса
curl -X POST http://127.0.0.1:5050/add \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "name=TestService&provider=Test&service_type=AI Development Tool&status=active"
```

**Ожидаемый результат:**
- Код ответа 302 (редирект)
- Создание нового сервиса

### 6. Тестирование Безопасности

```bash
# Проверка заголовков
curl -I http://127.0.0.1:5050/ | grep -E "(X-Content-Type-Options|X-Frame-Options|X-XSS-Protection)"

# Тест обработки ошибок
curl -I http://127.0.0.1:5050/nonexistent
curl -I http://127.0.0.1:5050/edit/999999
```

**Ожидаемый результат:**
- Наличие заголовков безопасности
- Корректная обработка 404 ошибок

## 🔍 Диагностика Проблем

### Проблемы с запуском сервера

```bash
# Проверка портов
lsof -i :5050
netstat -an | grep 5050

# Очистка процессов
lsof -ti:5050 | xargs kill -9

# Проверка логов
tail -f logs/app.log  # если есть
```

### Проблемы с зависимостями

```bash
# Проверка установленных пакетов
pip list | grep -E "(Flask|pywebview|cryptography)"

# Переустановка зависимостей
pip install --force-reinstall -r requirements.txt
```

### Проблемы с данными

```bash
# Проверка файлов данных
ls -la data/
file data/ai_services.json.enc

# Проверка конфигурации
cat config.json | python3 -m json.tool

# Проверка схемы
cat ai_services_schema.json | python3 -m json.tool
```

### Проблемы с YubiKey

```bash
# Проверка модуля
python3 -c "

auth = yubikey_auth.init_yubikey_auth('/tmp/test')
```

## 🚨 Частые Проблемы и Решения

### 1. Сервер не запускается

**Симптомы:** Ошибка "Address already in use"

**Решение:**
```bash
lsof -ti:5050 | xargs kill -9
```

### 2. Модуль YubiKey не найден

**Симптомы:** ImportError при запуске

**Решение:**
```bash
pip install yubico-client
```

### 3. Проблемы с шифрованием

**Симптомы:** Ошибки при работе с данными

**Решение:**
```bash
python3 tools/generate_key.py
```

### 4. GUI не открывается

**Симптомы:** Окно не появляется

**Решение:**
```bash
# Проверка PyWebView
python3 -c "import webview; print('PyWebView OK')"

# Запуск с отладкой
PYWEBVIEW_DEBUG=1 python3 run_app.py
```
