# Алгоритм работы AllManagerC

AllManagerC — локальное desktop-приложение: Flask обслуживает интерфейс, а PyWebView открывает его в отдельном окне. Сервер привязывается только к `127.0.0.1` и выбирает свободный порт.

## Запуск

```text
run_app.py → Flask в отдельном потоке → PyWebView → браузерный интерфейс
app.py    → Flask-маршруты и инициализация приложения
```

`run_app.py` переводит рабочий каталог в корень проекта. Упакованное приложение использует тот же серверный слой и не завершает чужие процессы.

## Инициализация профиля

При старте приложение:

1. Определяет каталог профиля (`ALLMANAGERC_DATA_DIR` имеет приоритет).
2. Загружает `.env`, `config.json` и настройки YubiKey.
3. Создаёт `data`, `uploads` и `logs` при отсутствии.
4. Загружает `SECRET_KEY`; если ключа нет, создаёт Fernet-ключ и сохраняет его в `.env`.
5. Находит активный зашифрованный файл `.enc` и проверяет его доступность.
6. Инициализирует локальный Flask-сервер и маршруты интерфейса.

Каталоги профиля: macOS `~/Library/Application Support/AllManagerC`, Windows `%APPDATA%\AllManagerC`, Linux `~/.local/share/AllManagerC`.

## Обработка запроса

Сначала проверяется локальный адрес и состояние сессии. При включённой защите запросы к рабочим страницам требуют `session['yubikey_authenticated']`. Страницы входа, статика и справочные маршруты остаются доступны для прохождения входа. Если не настроен ни один ключ или резервный пароль, пользователь направляется в `/yubikey/setup`.

## Работа с данными

`load_ai_services()` читает активный `.enc`, расшифровывает Fernet-ключом и загружает JSON. Поля, нужные только интерфейсу, создаются временно. `save_ai_services()` удаляет временные поля, сериализует данные, шифрует их и записывает обратно.

Импорт проверяет файл и внешний ключ. Экспорт создаёт зашифрованный файл или полный пакет. Смена ключа сначала создаёт резервную копию, затем перешифровывает данные. Старый абсолютный путь из перенесённой конфигурации не восстанавливает файл автоматически: исходный `.enc` и его ключ нужно импортировать отдельно.

## Пользовательские операции

- Добавление и редактирование обновляют сервисы и аккаунты.
- Пустой пароль дополнительного аккаунта сохраняет прежнее значение.
- Удаление всех сервисов требует подтверждения.
- Выход удаляет признак успешной аутентификации из сессии.
- Настройки языка сохраняются в профиле и поддерживают русский, English и 简体中文.

## Границы сборки

Сборщики macOS и Windows включают код, шаблоны, статику, переводы, схему и чистый конфиг. Они не включают `.env`, базы, ключи, загрузки и `yubikey_config.json`. Порядок сборки описан в [BUILD_MACOS.md](BUILD_MACOS.md) и [BUILD_WINDOWS.md](BUILD_WINDOWS.md).

Приложение рассчитано на локальный запуск, а не на публикацию Flask-сервера в сети. Модель защиты и ограничения описаны в [SECURITY.md](SECURITY.md), детали входа — в [АУТЕНТИФИКАЦИЯ.md](АУТЕНТИФИКАЦИЯ.md).
