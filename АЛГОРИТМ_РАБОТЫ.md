# Алгоритм работы AllManagerC

AllManagerC — локальное приложение с окном PyWebView и Flask-сервером. Сервер
слушает только `127.0.0.1` и при запуске выбирает свободный порт.

## Запуск

```text
run_app.py  →  GUI PyWebView  →  app.py
app.py      →  Flask для разработки и диагностики
```

`run_app.py` переводит процесс в корень проекта, запускает Flask в отдельном потоке
и открывает окно. Он не завершает чужие процессы на порту 5050. В упакованной версии
порт выдаёт `make_server`, а адрес появляется в терминале.

## Инициализация

При импорте `app.py` приложение:

1. Загружает `.env` проекта или профиль установленной версии.
2. Выбирает каталог данных: проект при разработке; `~/Library/Application Support/AllManagerC` на macOS; `%APPDATA%\\AllManagerC` на Windows; `~/.local/share/AllManagerC` на Linux. Путь можно переопределить `ALLMANAGERC_DATA_DIR`.
3. Загружает `config.json` и активный файл данных.
4. Инициализирует `yubikey_auth`, читая `yubikey_config.json`, статические пароли и разрешённые public ID.
5. Загружает `SECRET_KEY`; при отсутствии создаёт Fernet-ключ и сохраняет его в `.env`.
6. Создаёт `data`, `uploads` и `logs`.

## Обработка запроса

Сначала проверяется локальный IP. Если защита включена, проверяется
`session['yubikey_authenticated']`. Без сессии разрешены вход, статика, справка и
служебные маршруты; остальные запросы идут на `/yubikey/login`. Если защита включена,
но нет ключей и статических паролей, остальные страницы ведут на `/yubikey/setup`.

## Загрузка и сохранение данных

`load_ai_services()` читает `active_data_file`, расшифровывает бинарный `.enc`
через Fernet, разбирает JSON и добавляет временные `*_decrypted` для интерфейса.
`save_ai_services()` удаляет временные поля, сериализует JSON, шифрует его и
записывает обратно. Чувствительные поля аккаунтов остаются зашифрованными.

Если старый абсолютный путь недоступен, приложение ищет файл с тем же именем в
локальной `data`. Если ключ не подходит, данные не восстанавливаются — исходный
файл и ключ нужно сохранить отдельно.

Смена ключа создаёт резервную копию, перешифровывает вложенные поля и записывает
новый `.enc`. Перед этим всё равно сохраните `.env`, базу и `uploads`.

## Пользовательские действия

- Добавление и редактирование обновляют основной и дополнительные аккаунты.
- Пустой пароль дополнительной строки сохраняет прежний пароль.
- Импорт проверяет файл и ключ; экспорт создаёт зашифрованный файл или ZIP.
- Удаление всех сервисов требует подтверждения и очищает их иконки.
- Выход удаляет признак аутентификации из Flask-сессии.

## Профиль установленного приложения

Сборщик macOS включает код, шаблоны, статику, схему и чистый конфиг. `.env`, базы,
`uploads` и `yubikey_config.json` не попадают в приложение. Подробности — в
[BUILD_MACOS.md](BUILD_MACOS.md) и [DEPLOYMENT.md](DEPLOYMENT.md).

Это локальный менеджер, а не готовый публичный веб-сервис. Номер порта не является
паролем, ключ Fernet и база переносятся вместе, полный экспорт содержит ключ.
Ограничения входа описаны в [SECURITY.md](SECURITY.md).
