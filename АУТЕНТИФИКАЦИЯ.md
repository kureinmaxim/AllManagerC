# Аутентификация AllManagerC

Аутентификация защищает локальный профиль приложения. Она не превращает Flask-сервер в безопасный публичный сервис и не заменяет защиту учётной записи macOS или Windows.

## Способы входа

| Способ | Назначение | Источник настройки |
|---|---|---|
| YubiKey OTP | Основной онлайн-вход | Yubico Client ID и Secret Key |
| Статический пароль | Офлайн-резерв | `YUBIKEY_STATIC_PASSWORDS` в `.env` |
| Secret PIN | Локальный режим разработчика | `DEV_PIN`, `DEVELOPER_PIN` или `config.json` |

После успешного входа приложение устанавливает `session['yubikey_authenticated'] = True`. Сессионная cookie называется `allmanagerc_session`.

## Проверка запроса

1. Сервер принимает запросы только с локального адреса.
2. При выключенной защите рабочие страницы доступны без входа.
3. При включённой защите проверяется сессия.
4. Без сессии доступны вход, статика, справка и служебные маршруты.
5. Остальные запросы перенаправляются на `/yubikey/login`.
6. Если защита включена, но ключи не настроены, открывается `/yubikey/setup`.

## YubiKey OTP

Для онлайн-входа нужны Client ID и Secret Key Yubico. Приложение отправляет одноразовый OTP в YubiCloud и принимает только корректный ответ с проверкой подписи и повторного использования OTP.

Разрешённые ключи можно ограничить:

```env
YUBIKEY_ALLOWED_PUBLIC_IDS=cccccbgklrhh,aaaaaabbbbbb
```

Пустой список допускает автоматическую привязку public ID после первого успешного OTP согласно текущей логике приложения. Secret Key Yubico хранится в конфигурации профиля открытым текстом — ограничьте права доступа к этому профилю.

## Статические пароли

```env
YUBIKEY_STATIC_PASSWORDS=длинный-случайный-пароль,резервное-значение
```

Значения разделяются запятыми, являются постоянными секретами и не заменяют OTP. Храните `.env` только в профиле пользователя, после изменения перезапустите приложение и никогда не добавляйте файл в Git.

## Secret PIN

Приложение проверяет источники в порядке приоритета: `DEV_PIN`, `DEVELOPER_PIN`, значения `security.secret_pin` в `config.json`, затем встроенное резервное значение. Последнее предназначено только для совместимости и должно быть переопределено в рабочей конфигурации. После трёх неверных попыток маршрут временно блокируется.

## Восстановление

Перед изменением `.env`, `config.json` или `yubikey_config.json` сохраните копию профиля. Для восстановления нужны исходные `.enc` и `SECRET_KEY`: замена ключа не расшифрует старую базу. Если включённая защита блокирует вход, сначала сохраните профиль и обратитесь к процедуре восстановления из [SECURITY.md](SECURITY.md).

## Диагностика

| Симптом | Проверка |
|---|---|
| Редирект на setup | Есть ли ключ или `YUBIKEY_STATIC_PASSWORDS` в профиле |
| OTP отклонён | Client ID, Secret Key, сеть, время системы и public ID |
| Public ID запрещён | `YUBIKEY_ALLOWED_PUBLIC_IDS` и используемый ключ |
| После переноса нет данных | `.enc` и `.env` должны быть из одной установки |
| PIN не меняется | Приоритет `DEV_PIN` и `DEVELOPER_PIN` |

Журнал находится в `logs/security.log`. Это диагностический журнал, а не полный аудит и не гарантия маскирования каждого чувствительного значения.

Ограничения и порядок сообщения об уязвимостях описаны в [SECURITY.md](SECURITY.md). Практический сценарий настройки YubiKey находится в [docs/guides/YUBIKEY_QUICK_START.md](docs/guides/YUBIKEY_QUICK_START.md).
